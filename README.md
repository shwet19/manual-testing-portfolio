# Manual Testing & Bug Logging Portfolio

### 📌 Project Overview
This repository contains production-grade manual testing documentation for a live E-Commerce web application. The goal was to perform complete requirement mapping, functional test design, and track the end-to-end defect life cycle.

### 📊 Artifacts Included
1. **Test Scenario Matrix:** High-level scenarios covering critical flows (User Management, Cart Operations, Payment processing).
2. **Test Case Suite:** 50+ thoroughly mapped positive and negative test cases utilizing Boundary Value Analysis (BVA) and Equivalence Partitioning (EP).
3. **Bug Reports:** Standard JIRA-formatted defect logs complete with exact steps to reproduce, severity ratings, and defect tracking states.

### 🔍 Types of Testing Executed
- Functional & Integration Testing
- Smoke & Sanity Testing
- UI/UX Cross-Browser Verification
- Negative and Edge-Case Testing
